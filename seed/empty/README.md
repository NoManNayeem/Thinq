# Empty seed

Point `THINQ_SEED_PATH` here to start Thinq with no people and no documents. The sign-in page
then leads to a one-time setup that creates the first Admin, who can add people and groups and
upload documents. Add a `documents/` folder (and optionally `manifest.csv` and `users.csv`) to
sync files instead; see [../README.md](../README.md) for the formats.
